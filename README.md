# finki-scraper

Скриптава е направена за да не мора да рефрешаш Moodle како будала на секои 5 минути во сесија. Ботот сам проверува дали има нови соопштенија и ако најде PDF со распоред, ти кажува каде и кога полагаш.

### Што прави?

- **Login**: Се логира со твојот Moodle профил.
- **Auto-check**: Ги гледа сите предмети што ти се со ѕвездичка (starred).
- **PDF Parser**: Ако има закачен PDF, го отвора и го бара твојот индекс.
- **Easy Results**: Ти вади чист распоред во `results.json` (Индекс, Лаб, Време).
- **Announcements**: Ги зачувува сите нови вести во `all_announcements.json` за да не ги бараш по курсевите.

### Како да го пуштиш

1. Клонирај го репото.
2. `npm install`
3. Направи еден `.env` фајл и пополни го вака:

```env
# Moodle Credentials
USER=tvojot_user
PASS=tvojata_lozinka

# Индекси (comma-separated, no spaces)
INDEXI=123456,123123,233333
```

4. `npx tsx src/index.ts`

### Како работи тајмерот?

За да не те блокираат од Moodle дека си бот:

- **Преку ден**: Проверува на секои 2 часа.
- **Навечер (00:00 - 07:00)**: Проверува на секои 6 часа (дека и финки спие).

### Зошто го направив?

Наместо да одиш да инсталираш PDF и да се бараш со CTRL+F само си го отвораш `results.json` и таму ти пишува:
`1234 -> Лаб 138 -> 09:00`.
